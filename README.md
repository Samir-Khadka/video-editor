# Video Editor Agent

CLI video-editing toolkit for Samir's content pipeline. You send a video +
a short instruction ("make this a 60s reel with captions") and Muse runs
this toolkit to deliver the finished file. The CLI is the engine; Muse is
the agent interface.

Pure **stdlib + ffmpeg/ffprobe** — no moviepy, no torch, no opencv.
One optional dependency: `faster-whisper` (for `transcribe`).

## Install

```sh
# ffmpeg 8.x required (already on this machine: /usr/bin/ffmpeg)
ffmpeg -version

# optional: speech-to-text for auto-captions
TMPDIR=~/workspace/.tmp pip install --break-system-packages faster-whisper
```

Note: on this box `av` must be ≤13.x (`pip install "av==13.1.0"`) —
faster-whisper 1.2.1 passes `metadata_errors` to `av.open()`, which newer
PyAV removed.

## Commands

| Command | What it does |
|---|---|
| `probe in.mp4` | Show resolution, duration, fps, audio, size |
| `reframe in.mp4 out.mp4 [--to 9:16\|1:1\|16:9]` | Crop+scale to aspect (default 1080x1920) |
| `transcribe in.mp4 [-o out.srt] [--model tiny\|base] [--lang en]` | Speech → SRT, word timings collapsed to ≤8-word / ≤3s cues |
| `caption subs.srt in.mp4 out.mp4 [--style reel\|simple]` | Burn in bold outlined bottom-center subtitles |
| `cut-silence in.mp4 out.mp4 [--threshold -35] [--min 0.4]` | Remove silent spans, A/V stays in sync |
| `trim in.mp4 out.mp4 --start 5 --end 45` | Cut a range (seconds or H:M:S), accurate |
| `concat a.mp4 b.mp4 ... -o out.mp4` | Join clips (normalizes mixed inputs first) |
| `text in.mp4 out.mp4 --text "..." [--pos top\|center\|bottom] [--start 2] [--end 6]` | Text overlay with black border |
| `thumbnail in.mp4 -o thumb.jpg [--at 3]` | 1280px-wide still |
| `compress in.mp4 out.mp4 [--max-mb 90]` | Shrink to a target file size |
| `reel in.mp4 out.mp4 [--captions on\|off]` | **The money command:** reframe → transcribe → burn captions → compress ≤90MB |

All output commands refuse to overwrite unless `--force` is given, create
parent directories, and print human-readable progress.

## Examples

```sh
cd ~/workspace/video-editor

# 1. Inspect what you got
python3 video_agent.py probe ~/workspace/raw/talk.mp4

# 2. Raw clip -> captioned reel (does everything)
python3 video_agent.py reel ~/workspace/raw/talk.mp4 ~/workspace/done/reel.mp4

# 3. Manual pipeline: trim the good part, kill silences, reframe, caption, shrink
python3 video_agent.py trim raw.mp4 t1.mp4 --start 12 --end 68
python3 video_agent.py cut-silence t1.mp4 t2.mp4
python3 video_agent.py reframe t2.mp4 t3.mp4 --to 9:16
python3 video_agent.py transcribe t3.mp4 -o caps.srt
# (edit caps.srt if a word is wrong)
python3 video_agent.py caption caps.srt t3.mp4 t4.mp4 --style reel
python3 video_agent.py compress t4.mp4 final.mp4 --max-mb 90

# 4. Hook text + thumbnail for the post
python3 video_agent.py text final.mp4 hooked.mp4 --text "POV: your code finally works" --pos top --start 0 --end 3
python3 video_agent.py thumbnail hooked.mp4 -o cover.jpg --at 1.5
```

## Tests

```sh
cd ~/workspace/video-editor
python3 -m unittest discover -s tests   # 13 tests, fixtures generated by ffmpeg
```

The `transcribe` test runs only if `faster-whisper` imports and its tiny
model downloads; otherwise it skips (never fails).

## Limits (honest)

- No GPU on this box: `tiny` transcribes ~1 min of speech in well under a
  minute on CPU; `base` is slower. Long videos → transcribe once, reuse the SRT.
- RAM is tight (~500MB free typical): one ffmpeg job at a time; the `reel`
  pipeline runs stages sequentially for this reason.
- Captions are phrase-level (≤8 words), not per-word karaoke highlighting.
- `reframe` is a center crop — if the subject is off-center, trim/position
  manually first.
